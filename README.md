# 🛺 TukTuk El Marg 3D - Unity Engine Project

Full conversion of the Egyptian 3D TukTuk game from Godot 4 to **Unity Engine**.

## Features
- **Full El Marg City 3D Map**: Imported `city.glb` with 89 accurate building `BoxCollider`s and 16 3D street & shop signs.
- **Realistic Egyptian Tuk-Tuk Physics**: Procedural 3D model with driver NPC, suspension roll/pitch tilt, steering fork pivot, and spinning wheels.
- **AI Traffic**: Cars patrolling streets with obstacle detection.
- **Missions & Economy**: Passenger pickup and delivery, fare rewards, timer bonus, and workshop upgrades (Engine, Brakes, Seats).
- **Atmosphere & Visuals**: Day, Sunset, and Night lighting presets; 3 Camera modes; full mobile touch and keyboard support.

## How to Run in Unity
1. Open **Unity Hub**.
2. Click **Add project from disk** and select `TukTuk_El_Marg_Unity`.
3. Open with Unity 2021 LTS, 2022 LTS, 2023 LTS, or Unity 6.
4. Load `Assets/Scenes/MainScene.unity` and click **Play ▶**!
