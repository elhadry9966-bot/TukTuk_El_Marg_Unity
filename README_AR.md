# 🛺 توك توك المرج 3D - مشروع يونيتي (Unity Engine) المتكامل

تم تحويل مشروع لعبة **"توك توك المرج 3D"** بالكامل من محرك Godot 4 إلى **محرك Unity** بأعلى جودة واحترافية وبنية برمجية معيارية (Standard Unity Project Structure).

---

## 🌟 مميزات نسخة محرك يونيتي (Unity):

1. **خريطة المرج الثلاثية الأبعاد (El Marg 3D Map):**
   - نقل مجسم خريطة المرج الكامل `city.glb` مع ملفات الموديلات والعربيات (`microbus.glb`, `corolla.glb`, `hiace2000.glb`, `hiace2018.glb`, `hiace2020.glb`, `peugeot504.glb`).
   - إنشاء **89 صندوق تصادم (BoxCollider)** مطابق بدقة لأبعاد مباني شوارع المرج الأصلية لمنع التوك توك من اختراق المباني مع نظام ارتداد فيزيائي واقعي (Bounce Pushback).
   - **16 يافطة ومعلم حقيقي لشوارع ومحلات المرج** (قسم المرج، مطعم طشه، حلال ماركت المرج، فرن حلمي، شارع الترعة، شارع محمد حماد، شارع سيد عنبر، شارع البرماوي، شارع سويدان، شارع بدران، شارع محمد رجب، شارع شوقي، شارع صلاح الاقرع، شارع عبد الغفار الاقرع، شارع أم عويس، شارع حجاج سالم).

2. **فيزياء وتحكم التوك توك الشعبي المصري:**
   - بناء مجسم التوك توك المصري الأصلي برمجياً (`ProceduralTuktukBuilder.cs`) بالصاج والشاسيه والكابينة والألوان الشعبية وسائق التوك توك (Driver NPC)، ودوران العجلات ومحور التوجيه الأمامي (Steering Fork Pivot).
   - ميلان الشاسيه الواقعي أثناء الانعطاف السريع (Chassis Roll & Tilt) ورفع/خفض المقدمة أثناء البنزين والفرامل (Pitch).
   - إضاءة الكشاف الأمامي في الليل، وتوهج كشافات الفرامل الخلفية عند التهدئة.
   - كلاكس شعبي مصري مع رسائل خفيفة الظل: *"📯 بيب بيب! وسع لتوك توك المرج يا أسطى"*.

3. **حركة المرور والسيارات في الشارع (AI Traffic):**
   - سيارات تسير في شوارع المرج ذهاباً وإياباً وتستشعر المباني والعوائق وتلف تلقائياً بدون تصادمات عالقة.

4. **نظام المهمات والركاب والأجرة (Missions & Economy):**
   - علامات توصيل مضيئة ثلاثية الأبعاد (Mission Marker) مع مجسمات الركاب (Passengers).
   - ركوب زبائن من محطات مختلفة، وتوصيلهم خلال وقت محدد للحصول على أجرة وبونص وقت.
   - مؤشر مسافة وبوصلة حية للأماكن المستهدفة.

5. **الورشة والترقيات (Upgrades Workshop):**
   - **🚀 تعلية الموتور:** لزيادة السرعة القصوى وقوة التسارع.
   - **🛑 تطوير الفرامل والعفشة:** لقوة التوقف والرشاقة في الدوران بين الحواري.
   - **🪑 كراسي مريحة:** لزيادة تسعيرة الأجرة من الركاب.

6. **أجواء واقعية وكاميرا ديناميكية:**
   - **أوقات اليوم:** ☀️ نهار مشمس / 🌇 غروب ساحر / 🌙 ليل مع كشافات مضيئة وشابورة.
   - **أوضاع الكاميرا:** 🎥 قريبة (Third Person Close) / 🎥 بعيدة (Third Person Far) / 🎥 علوية (Top-Down).
   - **تحكم متعدد المنصات:** يدعم لوحة المفاتيح (WASD / الأسهم) + أزرار لمس تفاعلية على الشاشة للموبايل والتابلت.

## 📁 هيكل مجلدات المشروع (Project Structure):

```text
TukTuk_El_Marg_Unity/
├── Assets/

│   │   ├── GameManager.cs            # إدارة اللعبة والمهام والاقتصاد والترقيات
│   │   ├── PlayerController.cs       # فيزياء وتحكم التوك توك
│   │   ├── ProceduralTuktukBuilder.cs # بناء التوك توك ثلاثي الأبعاد برمجياً
│   │   ├── CitySetup.cs              # بناء شوارع ومعالم ويافطات ومباني المرج
│   │   ├── TrafficManager.cs         # حركة المرور وسيارات الشارع
│   │   ├── TrafficCar.cs             # تحكم كل سيارة في المرور
│   │   ├── CameraController.cs       # كاميرا التتبع ثلاثية الأوضاع
│   │   ├── MissionMarker.cs          # علامة وركاب المهمات
│   │   ├── UIController.cs           # واجهة المستخدم وأزرار الشاشة
│   │   └── HoldButton.cs             # دعم اللمس المتعدد لأزرار التحكم
│   └── Scenes/
│       └── MainScene.unity   # المشهد الرئيسي الجاهز للتشغيل
├── Packages/
│   └── manifest.json         # حزم ومكتبات يونيتي الرسمية
├── ProjectSettings/          # إعدادات المشروع ودقة العرض والمدخلات
└── README_AR.md              # هذا الدليل الشامل
```

## 🚀 كيفية تشغيل المشروع على Unity:

1. افتح تطبيق **Unity Hub** على جهازك.
2. اضغط على زر **Add** أو **Add project from disk**.
3. اختر مجلد المشروع: `TukTuk_El_Marg_Unity`.
4. افتح المشروع (متوافق مع إصدارات **Unity 2021 LTS, 2022 LTS, 2023 LTS, Unity 6**).
5. من نافذة المشروع تحت مجلد `Assets/Scenes/`، افتح مشهد:
   `MainScene.unity`
6. اضغط زر التشغيل **▶ (Play)** أعلى نافذة محرك يونيتي!

## 🎮 أزرار التحكم (Controls):

- **W / السهم لأعلى (↑):** بنزين وتسارع (Gas).
- **S / السهم لأسفل (↓):** فرامل ورجوع للخلف (Brake / Reverse).
- **A / السهم يسار (←):** انعطاف شمال (Steer Left).
- **D / السهم يمين (→):** انعطاف يمين (Steer Right).
- **على الموبايل والشاشات التاتش:** أزرار تفاعلية على الشاشة (بنزين، فرامل، شمال، يمين، كلاكس).
- **أزرار الواجهة:**
  - **🔧 الورشة:** فتح نافذة ترقية الموتور والفرامل والكراسي.
  - **☀️ نهار / 🌇 غروب / 🌙 ليل:** تغيير وقت وإضاءة اليوم.
  - **🎥 كاميرا:** التبديل بين الكاميرا القريبة والبعيدة والعلوية.
  - **🚗 العربية:** استعراض موديلات السيارات.
